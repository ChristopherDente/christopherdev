Integrating Hardware Barcode Scanners

How I built a Javascript event-listener system to capture rapid hardware scanner input for my standalone Barcode Reader System without requiring focused text inputs.

The "Invisible Keyboard" Problem

When I was building the Barcode Reader System, I needed a way for users to scan physical ID cards or inventory items. I bought a standard USB barcode reader and plugged it in.

The first thing you learn about hardware scanners is that they aren't magical devices requiring complex drivers. They act exactly like a USB keyboard!

When you scan a barcode, the scanner simply "types" the numbers very quickly and automatically presses the Enter key.

The Clunky Approach: Focused Inputs

The easiest way to capture this is to put an <input type="text"> on the screen and tell the user to click it before scanning.

The problem: In a fast-paced environment (like a checkout counter), users will forget to click the input box. They will scan their card, and nothing will happen.

The Seamless Approach: Global Key Listeners

To make the system seamless, I implemented a global Javascript event listener that detects rapid typing anywhere on the page.

How we tell humans and scanners apart:

  • Humans type at roughly 50-100 milliseconds per keystroke.
  • Hardware scanners type at 2-5 milliseconds per keystroke.

We can use this timing gap to intercept scanner data without blocking normal human typing!


let barcodeString = '';
let lastKeyTime = Date.now();

document.addEventListener('keypress', function(e) {
    const currentTime = Date.now();
    
    // If >20ms passed since last key, it's a human typing. Reset.
    if (currentTime - lastKeyTime > 20) {
        barcodeString = '';
    }
    
    // If the scanner pressed "Enter", process the barcode!
    if (e.key === 'Enter' && barcodeString.length > 3) {
        processEmployeeId(barcodeString);
        barcodeString = '';
    } else {
        barcodeString += e.key;
    }
    
    lastKeyTime = currentTime;
});

Why This Matters

By relying on Javascript event loops and timing functions rather than hardcoded <input> focuses, the application becomes completely hands-free. A user can walk up, scan their physical barcode (which you can simulate using the Barcode Generator on my Tools page), and the system instantly logs the scan without them ever needing to touch a mouse or keyboard.
