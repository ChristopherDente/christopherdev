A seamless hardware integration system that captures rapid scanner input for inventory or ID cards.

System Capabilities

The application has two distinct modes built directly into the UI:

1. Register Employee (Profiling)

When capturing a new employee's photo, the AI detects their face, performs deep profiling (Age, Gender, Emotion, and Race), crops the face perfectly, and securely registers them into the database (backend/known_faces).

2. Daily Time Record (Fast Attendance)

This mode optimizes for speed. When clocking in, it skips the heavy profiling algorithms and instantly compares the captured face against the database using deep neural networks. Successful recognitions are immediately logged into the Attendance Table (backend/attendance.csv).

AI Models Under the Hood

This system leverages state-of-the-art Deep Learning models to ensure enterprise-grade accuracy and speed:

Core Features

  • Face Detection (Finding the Face): Powered by the DeepFace framework. DeepFace abstracts the complexity of underlying models (like MTCNN or RetinaFace) to accurately detect faces and align them perfectly, even in varying lighting conditions or odd angles.
  • Face Recognition (Identity Matching): DeepFace also handles embedding extraction. It passes the cropped face through a deep convolutional neural network (like VGG-Face or Facenet) to generate a complex numerical vector. We then compute the cosine similarity between this vector and the known vectors in our database to instantly verify identity with an extremely low false-positive rate.
  • Emotion & Demographic Profiling: During the registration phase, secondary lightweight models evaluate the facial embedding to approximate age, gender, and current emotional state, providing rich demographic data for analytics dashboards.

Setup Guide (macOS / Windows)

1. Set up the Python Backend

  1. Open a terminal in the backend folder of this project. 
    cd path/to/free-dtr-facerecognition/backend
  2. Create a Virtual Environment (Python 3.11 recommended). 
    python -m venv venv
  3. Activate the Virtual Environment

    On macOS/Linux:

    source venv/bin/activate

    On Windows:

    venv\Scripts\activate
  4. Install the Requirements 
    pip install -r requirements.txt
  5. Start the Backend Server (Runs on port 8888). 
    python -m uvicorn app:app --host 0.0.0.0 --port 8888 --reload

2. Run the Frontend

For webcam compatibility, run the frontend on a local server rather than just double-clicking the HTML file.

  1. Open a NEW terminal in the frontend folder.
  2. Start a simple HTTP server: 
    python3 -m http.server 3000
  3. Open your web browser and navigate to: http://localhost:3000

3. Usage

  1. Make sure both servers are running.
  2. Start by switching to Register Employee mode, typing your name, and saving your profile.
  3. Switch back to Daily Time Record mode and capture your face to log your attendance!

Frequently Asked Questions (FAQ)

How accurate is the DeepFace framework?

DeepFace wraps several state-of-the-art models (like VGG-Face and Facenet) that achieve over 97% accuracy on standard benchmark datasets like Labeled Faces in the Wild (LFW). In a controlled office environment with adequate lighting, the system's accuracy is near-perfect.

Can this system handle multiple faces at once?

Yes, DeepFace is capable of detecting multiple bounding boxes in a single frame. However, the DTR application logic is optimized to focus on the largest face in the frame (usually the person standing in front of the terminal) to prevent accidental clock-ins from bystanders walking in the background.

Is the data stored securely?

Absolutely. While raw images are saved during registration for visual logging, the actual recognition engine compares mathematical embeddings (numerical arrays). These embeddings cannot be easily reverse-engineered into a human face, adding a layer of data privacy for your employees.
